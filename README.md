# gco

## Installation

```sh
go get github.com/adaviloper/gco
```

## Description

Git utility to simplify switching branches based on a provided pattern matching.

```sh
gco some-full-branch-name
gco <ticket-number>
gco <partial-string-match>
```

## Flags


| Flag | Name | Description |
|--- | --- | --- |
| -r | remote | Include parsing through remote branches |
---
